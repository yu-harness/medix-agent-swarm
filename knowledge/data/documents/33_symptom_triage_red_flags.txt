红旗症状识别与就医分诊（科普向）

说明：以下内容用于帮助识别需要尽快就医的情况，不能替代医生诊断。任何让你感到不安的严重症状都应及时就医。

一、需要立即拨打急救电话的情况

1. 心血管相关
   - 胸痛持续不缓解，尤其伴大汗、恶心、濒死感
   - 疼痛放射至左肩、下颌、背部
   - 突发意识丧失、呼之不应
   - 口角歪斜、一侧肢体无力、言语不清（脑卒中征象）

2. 呼吸相关
   - 严重呼吸困难，说话只能吐单字
   - 口唇发绀（青紫）
   - 气道异物梗阻，无法咳嗽或发声
   - 哮喘发作时吸入缓解药无效且持续加重

3. 其他急症
   - 大量呕血或便血
   - 突发剧烈头痛（"一生中最剧烈的头痛"）
   - 严重外伤、大出血、骨折外露
   - 抽搐持续不止
   - 过敏反应伴呼吸困难、喉头紧缩、全身皮疹

二、需要尽快就诊（24 小时内）的情况

1. 消化系统
   - 黑便或柏油样便（提示上消化道出血）
   - 进行性吞咽困难
   - 剧烈腹痛，板状腹（腹肌紧张如板）
   - 持续呕吐无法进食进水
   - 皮肤巩膜黄染

2. 泌尿系统
   - 尿量明显减少或无尿
   - 肉眼血尿伴血块
   - 腰痛伴高热寒战

3. 感染相关
   - 高热（体温 >39.5℃）持续不退
   - 发热伴意识改变、颈项强直
   - 发热伴皮肤瘀点瘀斑
   - 糖尿病患者的任何感染征象

4. 其他
   - 新发或性质改变的剧烈疼痛
   - 不明原因的明显体重下降（1 个月内下降 >5%）
   - 可触及的异常肿块，质地硬、边界不清、进行性增大
   - 视物突然模糊或失明
   - 大小便失禁伴会阴麻木、双下肢无力（马尾综合征征象）

三、可先居家观察的情况

1. 普通感冒
   - 流涕、咽痛、低热、轻度咳嗽
   - 多饮水、休息、对症处理
   - 一般 5-7 天自愈
   - 若高热超过 3 天或症状持续加重需就诊

2. 轻症胃肠不适
   - 无发热、能进食进水、无血便
   - 清淡饮食、补充水分与电解质
   - 持续超过 3 天或加重需就诊

3. 肌肉酸痛、轻度外伤
   - 休息、冷敷（48 小时内）、抬高患肢
   - 48 小时后可热敷
   - 若不能负重、明显畸形或疼痛剧烈需就诊排除骨折

四、就诊科室选择参考

| 主要症状 | 建议科室 |
|---|---|
| 胸痛、心悸、血压异常 | 心血管内科 |
| 呼吸困难、慢性咳嗽 | 呼吸内科 |
| 腹痛、腹泻、反酸 | 消化内科 |
| 头痛、头晕、肢体麻木 | 神经内科 |
| 关节疼痛、腰背痛 | 骨科 / 风湿免疫科 |
| 尿频尿急、血尿 | 泌尿外科 / 肾内科 |
| 皮疹、皮肤瘙痒 | 皮肤科 |
| 情绪低落、失眠、焦虑 | 精神心理科 / 睡眠门诊 |
| 儿童发热、咳嗽 | 儿科 |
| 外伤、需要缝合 | 急诊外科 |

五、就诊前准备清单

1. 症状记录
   - 何时开始、如何变化
   - 什么情况下加重或缓解
   - 伴随症状
   - 已用过什么药、效果如何

2. 携带资料
   - 既往病历与检查报告
   - 正在服用的全部药物（包括保健品）
   - 过敏史
   - 手术史与家族史

3. 检查前注意
   - 抽血查血脂血糖需空腹 8-12 小时
   - 腹部超声需空腹
   - 胃镜需空腹 6 小时以上
   - 部分检查前需停用特定药物，应提前咨询
