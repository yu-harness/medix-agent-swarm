## 判定细则

- embedding < 0.4 → **直接判错**（不再交 LLM）
- embedding ≥ 0.4 → 交 DeepSeek 输出 correct / partial / incorrect
- 主准确率（exact）**仅计 correct**；partial 单独汇报
- 空答、异常、超时 → 计错
- **裁判校准（相对基线）**：correct=覆盖金标关键医疗要点即可，不要求药名/偏方逐字；emb门禁由0.45降至0.40
