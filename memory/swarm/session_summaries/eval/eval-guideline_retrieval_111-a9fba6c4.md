## 【风险评估】

1. **传染风险极高**：麻疹是已知传染性最强的病毒性疾病之一，R₀值高达12-18，即在无免疫力人群中，1例患者平均可传染12-18人。主要通过飞沫传播，且**在密闭空间内病毒可悬浮空气中长达2小时**，即使患者离开仍可感染他人。
2. **“出疹前即已传染”的隐蔽风险**：麻疹患者在出疹前4天即具传染性，且此阶段传染性最强。此时患者症状类似重感冒，常正常参与社会活动，极易在不知不觉中造成聚集性疫情扩散。
3. **并发症风险不可忽视**：肺炎为最常见并发症，脑炎及远期罕见但致命的亚急性硬化性全脑炎（SSPE）需特别警惕。
4. **儿童及免疫低下人群风险突出**：未接种疫苗的婴幼儿、免疫力低下者及孕妇为重症高危人群，需重点关注。
5. **写作不当的误导风险**：若文档中未强调“疑似症状须及时就医”和“不可自行用药”，可能导致读者延误诊治或不当用药（尤其需警示含阿司匹林药物的使用）。
