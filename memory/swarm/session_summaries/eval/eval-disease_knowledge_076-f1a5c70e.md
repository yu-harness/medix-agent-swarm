## 【风险评估】

粗脖子病（医学上称**甲状腺肿大**）的治疗风险高度依赖于**病因诊断是否明确**。根据多位专科 Agent 的综合分析，存在以下关键风险点：

| 风险等级 | 风险情境 | 潜在后果 |
|---------|---------|---------|
| 🔴 **极高危** | 未明确病因即盲目补碘 | 若为甲亢，补碘会**显著加重病情**，甚至诱发**甲亢危象**（高热、心动过速、烦躁不安，属内科急症，可危及生命） |
| 🔴 **极高危** | 未明确病因即自行服用抗甲状腺药物 | 对桥本甲减或碘缺乏性甲状腺肿无效，且可能引起**粒细胞缺乏症**（表现为发热、咽痛，需立即就医） |
| 🟠 **高危** | 甲亢患者自行停药或中断治疗 | 甲亢复发率显著升高，反复发作增加心脏并发症（房颤、心衰）风险 |
| 🟠 **高危** | 桥本甲状腺炎孕妇未控制甲减 | 可导致胎儿**智力发育受损**，影响不可逆 |
| 🟡 **中危** | 缺碘性甲状腺肿补碘过量 | 可诱发**碘性甲亢**（Jod-Basedow效应）...
